# Retail Sales & Business Performance Analytics

## Overview

This project analyzes retail transaction data to evaluate sales performance, profitability, product performance, customer purchasing behavior, regional performance, and business trends.

The goal is to transform raw transaction data into meaningful business insights and develop an interactive business intelligence dashboard to support data-driven decision-making.

## Objectives

- Analyze sales and profit performance.
- Identify high-performing and underperforming products.
- Evaluate regional performance.
- Understand customer segments.
- Analyze discounts and their relationship with profitability.
- Identify seasonal sales trends.
- Build an interactive Power BI dashboard.
- Develop actionable business recommendations.

## Dataset

The project uses a retail Superstore transaction dataset containing information about orders, customers, products, regions, sales, discounts, quantities, and profits.

The raw dataset is not included in this repository.
